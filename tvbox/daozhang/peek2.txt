项目简介
PeekPili 是一款集影视点播、小说与漫画阅读功能于一体的跨平台应用。它支持多种视频源格式，旨在为用户提供一站式的娱乐体验。

核心功能概览
1. 影视播放：支持主流的 TVbox 视频源格式（如 T3、T4），具备多源管理、分类浏览、搜索及在线播放功能。
2. 小说阅读：配置小说源后，提供包含个性化设置、语音朗读、多端同步的书架与阅读器。
3. 漫画阅读：配置漫画源后，提供支持多种阅读模式与本地管理的漫画浏览体验。
4. 特色技术支持：   · JAR 支持：安卓端可运行 JAR 包视频源。 
  · PHP 运行时：应用内置环境，可直接本地运行 PHP 脚本源。  
 · 道长项目适配：支持相关本地脚本的搭建与运行（iOS 除外）。
· TMDB 媒体库：接入 TMDB API 后可享受海报墙等媒体库体验。

平台与使用方法
设置-接口配置-加号(手机和电脑端一样)。
· 支持平台：Android、iOS/iPadOS、Windows。
· 核心声明：本项目为学习交流而开发，不提供任何资源或接口，使用者需自行配置内容源并承担相应责任。

重要注意事项·
 电脑安装时建议使用英文路径，避免兼容性问题。
· 视频源配置优先使用在线链接，本地文件可能在部分设备上识别异常。
· 小说与漫画功能需在接口配置中正确添加对应类型的源后方会显示。
· 使用部分第三方脚本项目（如道长）时，请遵循其特定操作流程（如切换前需彻底退出应用），iOS 平台对此类功能支持有限。

PeekPili - PHP运行环境使用指南
功能简介
PeekPili 现已内置 PHP 运行环境，使应用能够直接运行 PHP 格式的爬虫脚本。这意味着以往仅在电脑端可用的 PHP 类型视频源（T4源），现在在手机和电脑客户端上均可直接使用。
快速开始
1. 进入功能页：打开应用，依次进入 设置 → 实验室 → PHP运行环境。
2. 环境安装（仅安卓需操作）：点击 “安装PHP” 按钮，等待约50MB的文件下载完成。请保持网络通畅。
3. 启动服务：设置端口（默认9980，通常无需修改），点击 “启动服务”。当状态显示为绿色“运行中”即表示成功。

管理PHP脚本
· 脚本存放目录：
  · 安卓：/storage/emulated/0/peekpili/php-scripts/ 
 · Windows：程序安装目录\data\php\scripts\
· 操作：将获取到的 .php 脚本文件放入上述目录。返回功能页点击“刷新”，即可在列表中对脚本进行测试或复制访问地址。
配置视频源
在T4源管理中添加新源，配置示例如下：

```json

{ 

 "key": "myphp", 

 "name": "示例PHP源",

 "type": 4, 

 "api": "http://127.0.0.1:9980/你的脚本名.php", 

 "searchable": 1, 

 "quickSearch": 1

}

```
配置完成后，确保PHP服务已启动，即可在首页或搜索中选用该源。

脚本测试
在脚本列表中点击“测试”，可针对首页、分类、搜索、详情、播放等接口进行调试。填写必要参数后运行测试，可帮助快速排查脚本问题。

常见问题
· 安装失败：请检查网络、存储空间，或尝试更换网络环境。
· 服务启动失败：可尝试更换端口号，或重新安装PHP环境。
· 脚本不显示/源无法使用：请确认脚本已放入正确目录、服务已启动、API地址配置准确，并可利用测试功能先行验证脚本是否正常。

温馨提示
· 使用PHP源前，请务必确认服务状态为“运行中”。
· 安卓端脚本为只读模式，编辑请借助第三方文件管理器或在电脑端完成。
· 遇到问题，优先使用内置的“测试”功能定位原因。

PeekPili 本地脚本包使用指南：
首要注意事项
· 安卓设备：
请在系统设置中，为 PeekPili 应用开启“所有文件访问权限”（或类似选项）。
· Windows 电脑：请务必以管理员身份运行软件，且软件的安装路径中不要包含中文名称的文件夹。
一、道长本地脚本包配置方法
1. 准备脚本包     
  手动下载道长本地包，解压后，将文件夹重命名为 drpy-node（请注意名称准确）。
2. 放置文件夹 
  · Windows 端：将 drpy-node 文件夹粘贴到 PeekPili-data 目录中。
  · 安卓端：将 drpy-node 文件夹粘贴到手机内部存储的 peekpili 目录下（如果该目录不存在，请手动创建）。
3. 配置与使用   
    在 PeekPili 的接口配置中，添加以下地址：

   ```  
 http://localhost:5757/config/1#nodejs 

  ```  

 配置完成后，重启应用即可使用。如遇加载问题，可尝试重新启动应用数次。
二、其他通用本地脚本包使用方法
1. 放置脚本包    
   将下载的本地脚本包（ZIP文件）解压到设备根目录（即打开文件管理器首先看到的顶层目录）。
2. 在应用内添加接口    
   打开 PeekPili，进入接口配置页面，点击输入框右侧的 文件夹图标，从根目录中选择你刚解压的脚本包文件夹。
3. 选择配置文件   
    在文件夹内选择对应的 .json 配置文件（如存在多个，请逐一尝试），并为该接口任意命名即可加载使用。
温馨提示：首次使用若未成功，请尝试完全关闭应用后重新启动，此过程可重复几次以确保正常加载。
